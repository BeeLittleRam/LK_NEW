# 2D Spine Animated Old Mage and Sea Pirate

Thank you for downloading the 2D Spine Old Mage and Sea Pirate Animation Pack

This package 2D characters, the Old Mage and Sea Pirate.

 Features
- 2 Animated Characters – Includes Old Mage and Sea Pirate.
- Ready-to-Use Assets – Import the characters into Unity and add them to your scene.
- Flexible Usage – Suitable for prototyping, game development, and final production.

 Quick Setup Guide (Unity)

1. Import Spine Runtime – Make sure the Spine-Unity runtime is installed in your Unity project. You can find the official installation guide on the [Spine Runtimes Documentation](https://esotericsoftware.com/spine-unity).
2. Import the Assets – Import this package into your Unity project.
3. Locate the Character Prefabs – Find the  Prefabs folder in the imported assets (You can also open the demo scene).
4. Add to Scene – Drag your chosen character prefab into the Scene or Hierarchy.
5. Play Animations – Select the character and use its `SkeletonAnimation` component to view or configure available animations.

Regarding Materials
If you are using the Universal Render Pipeline (URP),
you can download the official Spine-Unity URP shaders and materials from the Spine website.

You may also use your own materials, provided they are compatible with URP and render the
character correctly without visual issues such as incorrect colors, transparency, or shading.

For more detailed instructions, troubleshooting, and Spine-Unity setup references, please visit the official [Spine-Unity Documentation](https://esotericsoftware.com/spine-unity).
